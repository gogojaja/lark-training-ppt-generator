# 垂直节奏规范

> 基于 jingmei-ppt 方法论

## 1. 概述

**核心理念**：页面不是自由画布，而是有垂直节奏的条带结构。通过标准化的条带划分，确保所有页面具有一致的视觉节奏和层次感。

## 2. 五条带结构

### 2.1 条带定义

```
┌─────────────────────────────────────┐ ← 0%
│  ① 上下文条带 (Context Band)        │ ← 0-8%
├─────────────────────────────────────┤ ← 8%
│  ② 主张条带 (Claim Band)           │ ← 8-15%
├─────────────────────────────────────┤ ← 15%
│                                     │
│  ③ 证据区 (Evidence Zone)          │ ← 15-82%
│                                     │
├─────────────────────────────────────┤ ← 82%
│  ④ 含义/来源条带 (Meaning Band)    │ ← 82-92%
├─────────────────────────────────────┤ ← 92%
│  ⑤ 页脚安全区 (Footer Safe Zone)   │ ← 92-100%
└─────────────────────────────────────┘ ← 100%
```

### 2.2 各条带详细说明

#### ① 上下文条带 (Context Band) — 0-8%

**功能**：页面定位和导航信息
**内容**：
- 章节标签（Section Label）
- 面包屑导航
- 页码
- Logo

**视觉特征**：
- 字号最小（10-12pt）
- 颜色最浅（灰色系）
- 视觉权重最低

**设计规则**：
- 高度固定为页面高度的8%
- 内容垂直居中
- 左对齐或右对齐

#### ② 主张条带 (Claim Band) — 8-15%

**功能**：页面核心结论/标题
**内容**：
- 页面主标题（Claim）
- 副标题
- 关键数字

**视觉特征**：
- 字号最大（28-36pt）
- 字体加粗
- 颜色最深或最醒目

**设计规则**：
- 高度为页面高度的7%
- 与上下文条带之间有明显停顿（至少8px间距）
- 标题陈述主张，而非仅仅描述话题

#### ③ 证据区 (Evidence Zone) — 15-82%

**功能**：支撑主张的核心内容
**内容**：
- 图表
- 表格
- 文本段落
- 卡片
- 流程图

**视觉特征**：
- 占据页面最大空间（67%）
- 内容密度根据场景调整
- 视觉层次分明

**设计规则**：
- 内容从15%位置开始
- 底部不超过82%
- 各模块之间有清晰的视觉分隔
- 避免内容过于拥挤

#### ④ 含义/来源条带 (Meaning Band) — 82-92%

**功能**：解读、行动、来源标注
**内容**：
- 数据解读
- 行动建议
- 来源标注
- 方法论说明

**视觉特征**：
- 字号较小（10-12pt）
- 颜色较浅
- 位于证据区下方

**设计规则**：
- 高度为页面高度的10%
- 与证据区之间有明显分隔
- 来源可读但处于从属地位

#### ⑤ 页脚安全区 (Footer Safe Zone) — 92-100%

**功能**：页面收尾和品牌标识
**内容**：
- 页码
- 公司Logo
- 版权信息
- 留白

**视觉特征**：
- 视觉权重最低
- 保持干净简洁

**设计规则**：
- 高度固定为页面高度的8%
- 内容垂直居中
- 避免内容溢出到此区域

## 3. 垂直节奏计算

### 3.1 标准16:9画布

**画布尺寸**：
- 宽度：12192000 EMU (33.867 cm)
- 高度：6858000 EMU (19.05 cm)

**条带高度计算**：
```
上下文条带：6858000 × 0.08 = 548640 EMU (1.524 cm)
主张条带：6858000 × 0.07 = 480060 EMU (1.3335 cm)
证据区：6858000 × 0.67 = 4594860 EMU (12.7635 cm)
含义条带：6858000 × 0.10 = 685800 EMU (1.905 cm)
页脚安全区：6858000 × 0.08 = 548640 EMU (1.524 cm)
```

### 3.2 间距系统

**宏观间距**（条带之间）：
- 上下文 ↔ 主张：8px (36200 EMU)
- 主张 ↔ 证据：12px (54300 EMU)
- 证据 ↔ 含义：8px (36200 EMU)
- 含义 ↔ 页脚：8px (36200 EMU)

**中观间距**（证据区内部）：
- 面板之间：16px (72400 EMU)
- 列之间：16px (72400 EMU)
- 图表组之间：12px (54300 EMU)

**微观间距**（元素内部）：
- 行高：1.5倍
- 标签到值的距离：4px (18100 EMU)
- 项目符号间距：6px (27150 EMU)
- 文本框内边距：8px (36200 EMU)

## 4. 页面类型变体

### 4.1 标准内容页

```
上下文条带：章节标签 + 页码
主张条带：页面标题
证据区：正文/列表/卡片
含义条带：来源/注释
页脚安全区：页码 + Logo
```

### 4.2 封面页

```
上下文条带：（空）
主张条带：（空）
证据区：主标题 + 副标题 + 装饰
含义条带：日期/版本/作者
页脚安全区：Logo
```

**变体说明**：封面页的证据区占据更大空间（15-92%），主张条带融入证据区。

### 4.3 目录页

```
上下文条带：目录标题
主张条带：（空）
证据区：章节列表
含义条带：（空）
页脚安全区：页码
```

### 4.4 章节首页

```
上下文条带：（空）
主张条带：PART XX + 章节标题
证据区：副标题 + 描述
含义条带：（空）
页脚安全区：页码
```

**变体说明**：章节首页的主张条带占据更大空间（8-30%），证据区用于副标题和描述。

### 4.5 数据密集页

```
上下文条带：章节标签 + 页码
主张条带：页面标题
证据区：多个图表/表格（网格布局）
含义条带：数据解读 + 行动建议
页脚安全区：来源 + 方法论
```

## 5. 设计规则

### 5.1 必须遵守

1. **条带顺序固定**：上下文 → 主张 → 证据 → 含义 → 页脚
2. **主张条带必须有内容**：即使是空的，也要保留空间
3. **底部必须收尾**：不能内容用完就停，必须有收尾元素
4. **证据区不能溢出**：内容不能超过82%位置

### 5.2 建议遵守

1. **标题与证据之间有停顿**：至少12px间距
2. **各面板视觉权重有主次**：避免平均分配
3. **来源和注释可读但不抢眼**：10-12pt，灰色
4. **缩略图模式下仍能识别层级**：灰度测试

### 5.3 禁止事项

1. **标题贴着第一个内容模块**：缺少视觉停顿
2. **底部内容戛然而止**：没有收尾元素
3. **各模块视觉权重相等**：没有主次之分
4. **装饰元素纯粹填充**：不支持沟通目标
