# Skill: business-content-skill

# 业务内容页生成技能

## 1. 元数据

- **技能名称**：business-content-skill
- **技能版本**：v2.0.0
- **发布日期**：2026-08-17
- **技能定位**：从 Word 文档提取业务规则、要点和关键信息，生成专业的业务内容PPT页面
- **适用场景**：业务规则、限制条件、办理要求、业务要点、关键信息、重要提示、核心规则
- **合并说明**：本技能由 business-rules-skill 和 key-points-skill 合并而成

## 2. 工作流

```
Word文档 → ①提取业务内容 → ②分类整理 → ③生成PPT页面
```

### Step 1：提取业务内容

**识别关键词**：
- **规则类**："不允许""禁止""不得""必须""需要""要求""限制""条件"
- **要点类**："业务要点""关键信息""重要提示""核心规则"
- **其他**："注意事项""重要提醒""审批""审核""授权"

**提取规则**：
1. 找到业务内容相关段落
2. 保留编号和层级结构
3. 识别内容类型（规则/要点/提示）

### Step 2：分类整理

**内容分类**：

#### 2.1 规则类内容
1. **限制类规则**：不允许办理的情况（🚫 红色标记）
2. **要求类规则**：必须满足的条件（✅ 绿色标记）
3. **审批类规则**：需要上级授权的情况（⚠️ 黄色标记）

#### 2.2 要点类内容
1. **证件要求**：身份证件相关规则（📋 蓝色图标）
2. **账户限制**：账户状态相关规则（🏦 绿色图标）
3. **办理范围**：异地/跨行办理规则（📍 橙色图标）
4. **收费标准**：费用相关规则（💰 黄色图标）
5. **系统设置**：默认配置相关规则（⚙️ 灰色图标）

**输出格式**：
```json
{
  "title": "业务内容",
  "subtitle": "规则与要点汇总",
  "content_type": "rules|points|mixed",
  "sections": [
    {
      "type": "restriction",
      "label": "限制类规则",
      "icon": "🚫",
      "items": [
        "不允许代理",
        "身份证件过期不允许办理",
        "涉案账户不允许办理"
      ]
    },
    {
      "type": "requirement",
      "label": "要求类规则",
      "icon": "✅",
      "items": [
        "需要有效身份证件",
        "需要人脸识别通过"
      ]
    },
    {
      "type": "point_category",
      "label": "证件要求",
      "icon": "📋",
      "items": [
        "需要有效身份证件",
        "证件过期不允许办理"
      ]
    }
  ]
}
```

## 3. 生成脚本

```bash
# 使用方法（默认自动识别内容类型）
py -3 生成脚本/gen_business_content.py 输入文档/操作手册.docx --out 业务内容.pptx

# 指定内容类型为规则类
py -3 生成脚本/gen_business_content.py 输入文档/操作手册.docx --type rules --out 业务规则.pptx

# 指定内容类型为要点类
py -3 生成脚本/gen_business_content.py 输入文档/操作手册.docx --type points --out 业务要点.pptx

# 自定义标题
py -3 生成脚本/gen_business_content.py 输入文档/操作手册.docx --title "签约业务规则与要点" --out 业务内容.pptx
```

## 闭环执行系统

### 1. 任务入口
- **输入**：Word文档（.docx格式），包含业务规则、要点、关键信息等章节
- **前置**：
  - 文档已存在于本地文件系统
  - Python 3.8+ 已安装
  - 生成脚本 `gen_business_content.py` 可用
- **不适用**：
  - 文档为PDF或图片格式
  - 文档不包含业务规则或要点相关章节
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 文档已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取Word文档，识别业务内容章节
- **执行步骤 2**：提取内容并分类整理（规则/要点/混合）
- **执行步骤 3**：生成PPT页面并输出文件
- **所需工具/脚本**：`gen_business_content.py`、python-docx库
- **输入输出约束**：
  - 输入：Word文档路径、内容类型（可选）
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含业务内容页面）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有识别到的业务内容
  3. 布局符合选定的模板样式
  4. 规则标记/要点图标正确显示
- **失败条件**：
  1. 文件生成失败
  2. 未识别到业务内容章节
  3. 内容分类错误
  4. 布局严重错乱
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. 文件读取失败（文件不存在/格式错误）
  2. 章节识别失败（未找到业务内容）
  3. 内容分类失败
  4. 生成脚本执行失败
- **恢复策略**：检查文件路径和格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如文档格式异常）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（业务内容页面）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：文档路径、输出路径、内容类型、识别到的内容数量
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
