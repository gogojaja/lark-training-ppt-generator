# Skill: key-points-skill

# 业务要点页生成技能

## 1. 元数据

- **技能名称**：key-points-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取业务要点和关键信息，生成专业的要点汇总PPT页面
- **适用场景**：业务要点、关键信息、重要提示、核心规则

## 2. 工作流

```
Word文档 → ①提取业务要点 → ②分类整理 → ③生成PPT页面
```

### Step 1：提取业务要点内容

**识别关键词**：
- "业务要点""关键信息"
- "重要提示""核心规则"
- "证件要求""账户限制"
- "异地办理""收费标准"

**提取规则**：
1. 找到"业务要点"或类似章节标记
2. 提取后续段落中的要点内容
3. 保留编号和层级结构

### Step 2：分类整理

**要点分类**：
1. **证件要求**：身份证件相关规则
2. **账户限制**：账户状态相关规则
3. **办理范围**：异地/跨行办理规则
4. **收费标准**：费用相关规则
5. **系统设置**：默认配置相关规则

**输出格式**：
```json
{
  "title": "业务要点",
  "subtitle": "关键信息汇总",
  "categories": [
    {
      "name": "证件要求",
      "icon": "📋",
      "items": [
        "需要有效身份证件",
        "证件过期不允许办理"
      ]
    },
    {
      "name": "账户限制",
      "icon": "🏦",
      "items": [
        "涉案账户不允许办理",
        "注销账户不允许办理"
      ]
    }
  ]
}
```

### Step 3：生成PPT页面

**页面布局**：
```
┌─────────────────────────────────────┐
│  业务要点                            │ ← 标题栏（绿色背景）
├─────────────────────────────────────┤
│  关键信息汇总                         │ ← 副标题
├─────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐          │
│  │  📋     │  │  🏦     │          │ ← 要点卡片
│  │ 证件要求 │  │ 账户限制 │          │
│  ├─────────┤  ├─────────┤          │
│  │ • 要点1  │  │ • 要点1  │          │
│  │ • 要点2  │  │ • 要点2  │          │
│  └─────────┘  └─────────┘          │
│                                     │
│  ┌─────────┐  ┌─────────┐          │
│  │  💰     │  │  ⚙️     │          │
│  │ 收费标准 │  │ 系统设置 │          │
│  ├─────────┤  ├─────────┤          │
│  │ • 要点1  │  │ • 要点1  │          │
│  └─────────┘  └─────────┘          │
└─────────────────────────────────────┘
```

**配色方案**：
- 标题栏：深绿 #006100，文字白色 #FFFFFF
- 要点卡片：白色背景 #FFFFFF，灰色边框 #E0E0E0
- 分类图标：彩色图标（📋蓝/🏦绿/💰黄/⚙️灰）
- 要点内容：深灰文字 #333333

## 3. 生成脚本

```bash
# 使用方法
py -3 生成脚本/gen_key_points.py 输入文档/操作手册.docx --out 业务要点.pptx

# 自定义标题
py -3 生成脚本/gen_key_points.py 输入文档/操作手册.docx --title "签约业务要点" --out 业务要点.pptx
```

## 4. 样式规范

| 元素 | 字号 | 字体 | 颜色 |
|------|------|------|------|
| 页面标题 | 28pt | 微软雅黑 | 白色 |
| 副标题 | 18pt | 微软雅黑 | 深灰 |
| 分类名称 | 16pt | 微软雅黑 | 深灰 |
| 分类图标 | 24pt | Segoe UI Emoji | 彩色 |
| 要点内容 | 14pt | 微软雅黑 | 深灰 |

## 闭环执行系统

### 1. 任务入口
- **输入**：Word文档（.docx格式），包含业务要点、关键信息、重要提示等章节
- **前置**：
  - 文档已存在于本地文件系统
  - Python 3.8+ 已安装
  - 生成脚本 `gen_key_points.py` 可用
- **不适用**：
  - 文档为PDF或图片格式
  - 文档不包含业务要点相关章节
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 文档已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取Word文档，识别业务要点章节
- **执行步骤 2**：提取要点内容并分类整理
- **执行步骤 3**：生成PPT页面并输出文件
- **所需工具/脚本**：`gen_key_points.py`、python-docx库
- **输入输出约束**：
  - 输入：Word文档路径
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含业务要点卡片布局）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有识别到的要点分类
  3. 布局符合样式规范
- **失败条件**：
  1. 文件生成失败
  2. 未识别到业务要点章节
  3. 布局严重错乱
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. 文件读取失败（文件不存在/格式错误）
  2. 章节识别失败（未找到业务要点）
  3. 生成脚本执行失败
- **恢复策略**：检查文件路径和格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如文档格式异常）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（业务要点页面）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：文档路径、输出路径、识别到的要点数量
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
