# Skill: key-points-skill

# 业务要点页生成技能

## 1. 元数据

- **技能名称**：key-points-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取业务要点和关键信息，生成专业的要点汇总PPT页面
- **适用场景**：业务要点、关键信息、重要提示、核心规则

## 2. 工作流

```
Word文档 → ①提取业务要点 → ②分类整理 → ③生成PPT页面
```

### Step 1：提取业务要点内容

**识别关键词**：
- "业务要点""关键信息"
- "重要提示""核心规则"
- "证件要求""账户限制"
- "异地办理""收费标准"

**提取规则**：
1. 找到"业务要点"或类似章节标记
2. 提取后续段落中的要点内容
3. 保留编号和层级结构

### Step 2：分类整理

**要点分类**：
1. **证件要求**：身份证件相关规则
2. **账户限制**：账户状态相关规则
3. **办理范围**：异地/跨行办理规则
4. **收费标准**：费用相关规则
5. **系统设置**：默认配置相关规则

**输出格式**：
```json
{
  "title": "业务要点",
  "subtitle": "关键信息汇总",
  "categories": [
    {
      "name": "证件要求",
      "icon": "📋",
      "items": [
        "需要有效身份证件",
        "证件过期不允许办理"
      ]
    },
    {
      "name": "账户限制",
      "icon": "🏦",
      "items": [
        "涉案账户不允许办理",
        "注销账户不允许办理"
      ]
    }
  ]
}
```

### Step 3：生成PPT页面

**页面布局**：
```
┌─────────────────────────────────────┐
│  业务要点                            │ ← 标题栏（绿色背景）
├─────────────────────────────────────┤
│  关键信息汇总                         │ ← 副标题
├─────────────────────────────────────┤
│  ┌─────────┐  ┌─────────┐          │
│  │  📋     │  │  🏦     │          │ ← 要点卡片
│  │ 证件要求 │  │ 账户限制 │          │
│  ├─────────┤  ├─────────┤          │
│  │ • 要点1  │  │ • 要点1  │          │
│  │ • 要点2  │  │ • 要点2  │          │
│  └─────────┘  └─────────┘          │
│                                     │
│  ┌─────────┐  ┌─────────┐          │
│  │  💰     │  │  ⚙️     │          │
│  │ 收费标准 │  │ 系统设置 │          │
│  ├─────────┤  ├─────────┤          │
│  │ • 要点1  │  │ • 要点1  │          │
│  └─────────┘  └─────────┘          │
└─────────────────────────────────────┘
```

**配色方案**：
- 标题栏：深绿 #006100，文字白色 #FFFFFF
- 要点卡片：白色背景 #FFFFFF，灰色边框 #E0E0E0
- 分类图标：彩色图标（📋蓝/🏦绿/💰黄/⚙️灰）
- 要点内容：深灰文字 #333333

## 3. 生成脚本

```bash
# 使用方法
py -3 生成脚本/gen_key_points.py 输入文档/操作手册.docx --out 业务要点.pptx

# 自定义标题
py -3 生成脚本/gen_key_points.py 输入文档/操作手册.docx --title "签约业务要点" --out 业务要点.pptx
```

## 4. 样式规范

| 元素 | 字号 | 字体 | 颜色 |
|------|------|------|------|
| 页面标题 | 28pt | 微软雅黑 | 白色 |
| 副标题 | 18pt | 微软雅黑 | 深灰 |
| 分类名称 | 16pt | 微软雅黑 | 深灰 |
| 分类图标 | 24pt | Segoe UI Emoji | 彩色 |
| 要点内容 | 14pt | 微软雅黑 | 深灰 |
