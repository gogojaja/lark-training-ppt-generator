# 题型识别规范

> quiz-extraction-skill 领域规则：题型枚举、识别信号、抽取要点。
> 依据：教育测评 QTI 3.0 思想 + 国内题库通用格式（Word/在线考试平台导入规范）裁剪。

## 题型枚举（JSON `type` 取值）

| type | 中文 | 识别信号 | answer 规则 |
|------|------|---------|------------|
| `single_choice` | 单选题 | 题干 + 若干选项；题头出现「单选」「最佳选择」；答案标记「答案：A」「正确答案：A」 | 恰好 1 项，如 `["A"]` |
| `multiple_choice` | 多选题/不定项 | 题干 + 选项；题头出现「多选」「不定项」；答案标记多个字母如「ABC」 | ≥1 项，如 `["A","C"]` |
| `true_false` | 判断题 | 题干为陈述句；题头出现「判断」「对错」；答案标记「正确/错误」「对/错」「T/F」「√/×」 | 归一为 `["正确"]` 或 `["错误"]` |
| `fill_blank` | 填空题 | 题干含下划线 `____`、方括号 `[ ]`、括号 `（ ）` 空位；答案标记对应每空 | 每空一项，如 `["张三","2026"]` |
| `short_answer` | 简答题/问答 | 题头出现「简答」「问答」「论述」「计算」；无固定选项 | 参考要点，可多项 |

## 选择题选项与答案的关联规则

- `options` 数组元素自带字母前缀，如 `["A. 培训制度", "B. 签约流程"]`；输出时保留原前缀
- 答案用选项字母（大写）表示，`normalize_quiz.py` 自动大写归一
- 选项超出 F（>6 个）时：保留全部选项，但 CSV 仅映射 A~F 六列，多余选项合并进题干或选择 `option_f` 之外列留空并记录 warning
- 题干末尾出现「（）」或「___」的选项题，其答案是字母，不是空位文字

## 判断题归一规则（normalize_quiz.py 内置）

| 原文 | 归一 |
|------|------|
| 正确 / 对 / T / TRUE / √ | `["正确"]` |
| 错误 / 错 / F / FALSE / × | `["错误"]` |

## 填空题多空规则

- 多个空位按出现顺序对应 `answer` 数组多项
- 空位标记统一：`___`（下划线）、`[ ]`、`（ ）`，AI 抽取时在题干中原样保留
- 答案不明确时留空数组（validate 仅 warning，不阻断）

## 简答题答案要点

- `answer` 存放参考答案要点，多项用数组；`analysis` 存放采分点/评分说明
- 无参考答案时留空数组 + warning

## 题型混排与板块

- 文档常按板块混排（如「一、单选题；二、多选题」），`section` 记录板块标题
- 同一板块连续小题放入不同 group（每板块至少 1 个 group），或按板块聚合为 1 个 group 均可，以 `section` 对齐即可
