# 题组结构规范

> quiz-extraction-skill 领域规则：group（题组）与共享题干的处理。

## 什么是题组（group）

题组是把共享同一阅读材料/案例背景的多道小题聚合为一组的结构。典型场景：

- 阅读理解：一篇文章 + 多道单选
- 材料分析：一段案例 + 多道判断/问答
- 组合题：一个大题下设 (1)(2)(3) 子问

## 结构要求（对齐 schemas/quiz_schema.json）

```json
{
  "group_id": "G1",
  "section": "四、材料分析",
  "shared_stem": "阅读以下材料：xxx",
  "source_pages": [4, 5],
  "questions": [
    { "qid": "G1-Q1", "type": "single_choice", "stem": "根据材料，下列正确的是…" },
    { "qid": "G1-Q2", "type": "short_answer", "stem": "结合材料说明…" }
  ]
}
```

## 关键规则

1. **共享题干只写一次**：`shared_stem` 存放材料全文，小题 `stem` 不得重复抄写材料，只写提问部分
2. **小题不重编材料**：AI 抽取时禁止把共享题干复制到每个小题
3. **跨页题组**：材料跨页时 `source_pages` 记录全部涉及页号；小题 `source_page` 记录各自所在页
4. **同板块聚合**：普通单选题板块（无共享材料）可按板块聚合为一个 group（`shared_stem` 为空），或每节一组
5. **子问拆分**：形如 `(1)(2)(3)` / `①②③` 的子问按小题拆入 `questions`

## 共享图片/表格

- `shared_image` 存放共享配图路径（可选）；无图可省略
- 图片/表格在源文档中的位置通过 `source_page` 定位，不做重排

## 边界情况

- 材料题与小题分离（材料在上一页、小题在下一页）：仍聚合为同一 group，`source_pages` 跨页
- 一个 group 内小题题型可混排（如 2 单选 + 1 简答），分别标注 `type`
