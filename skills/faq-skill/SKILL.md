# Skill: faq-skill

# 常见问题页生成技能

## 1. 元数据

- **技能名称**：faq-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取常见问题和解决方案，生成专业的FAQ PPT页面
- **适用场景**：常见问题、故障处理、异常情况、用户疑问

## 2. 工作流

```
Word文档 → ①提取常见问题 → ②问答配对 → ③生成PPT页面
```

### Step 1：提取常见问题内容

**识别关键词**：
- "常见问题""FAQ"
- "问题""疑问"
- "异常情况""故障处理"
- "注意事项""特别提醒"

**提取规则**：
1. 找到问题相关的段落
2. 提取问题和对应答案
3. 识别注意事项和特别提醒

### Step 2：问答配对

**问题分类**：
1. **办理类问题**：如何办理、需要什么材料
2. **异常类问题**：人脸识别失败、证件读取失败
3. **规则类问题**：限制条件、收费标准
4. **系统类问题**：系统异常、设备故障

**输出格式**：
```json
{
  "title": "常见问题",
  "subtitle": "FAQ",
  "questions": [
    {
      "category": "办理类",
      "q": "如何办理个人综合签约？",
      "a": "客户携带有效身份证件到网点，由柜员通过交易代码036101办理。"
    },
    {
      "category": "异常类",
      "q": "人脸识别不通过怎么办？",
      "a": "由上一级管理人员进行现场审核授权。"
    }
  ]
}
```

### Step 3：生成PPT页面

**页面布局**：
```
┌─────────────────────────────────────┐
│  常见问题                            │ ← 标题栏（紫色背景）
├─────────────────────────────────────┤
│  FAQ                                 │ ← 副标题
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐   │
│  │ Q: 如何办理个人综合签约？     │   │ ← 问题（蓝色）
│  │                             │   │
│  │ A: 客户携带有效身份证件...    │   │ ← 答案（黑色）
│  └─────────────────────────────┘   │
│                                     │
│  ┌─────────────────────────────┐   │
│  │ Q: 人脸识别不通过怎么办？     │   │
│  │                             │   │
│  │ A: 由上一级管理人员...       │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**配色方案**：
- 标题栏：深紫 #6B21A8，文字白色 #FFFFFF
- 问题文字：蓝色 #2E75B6，加粗
- 答案文字：深灰 #333333
- 问答卡片：白色背景 #FFFFFF，灰色边框 #E0E0E0

## 3. 生成脚本

```bash
# 使用方法
py -3 生成脚本/gen_faq.py 输入文档/操作手册.docx --out 常见问题.pptx

# 自定义标题
py -3 生成脚本/gen_faq.py 输入文档/操作手册.docx --title "签约业务FAQ" --out 常见问题.pptx
```

## 4. 样式规范

| 元素 | 字号 | 字体 | 颜色 |
|------|------|------|------|
| 页面标题 | 28pt | 微软雅黑 | 白色 |
| 副标题 | 18pt | 微软雅黑 | 深灰 |
| 问题文字 | 16pt | 微软雅黑（加粗） | 蓝色 |
| 答案文字 | 14pt | 微软雅黑 | 深灰 |
| 问答卡片 | - | - | 白色背景 |
