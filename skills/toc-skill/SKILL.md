# 目录页生成技能

## 1. 元数据

- **技能名称**：toc-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12

## 3. 工作流

```
章节列表 → ①选择模板 → ②配置样式 → ③生成PPT
```

### Step 1：收集目录信息

**必需信息**：
- 章节列表：包含章节编号和标题

**可选信息**：
- 页码：每个章节的起始页码
- 描述：章节简要描述

### Step 2：选择模板和配色

**模板选择原则**：
- 标准目录：通用场景
- 卡片式目录：现代风格
- 侧边栏目录：正式汇报

**配色选择原则**：
- 专业蓝：技术/业务类
- 商务灰：管理/行政类
- 活力橙：培训/宣导类

### Step 3：生成目录页

**生成脚本**：
```bash
# 使用默认模板
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则,操作步骤,业务要点" --out 目录.pptx

# 指定模板和配色
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则" --template card --preset blue --out 目录.pptx

# 完整参数
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则,操作步骤" --titles "场景说明,业务规则,操作步骤" --template sidebar --preset gray --out 目录.pptx
```

## 5. 最佳实践

### 5.1 设计原则

1. **层次清晰**：通过编号、字体大小区分信息层次
2. **对齐美观**：保持元素对齐，提升可读性
3. **颜色协调**：使用统一的配色方案
4. **留白适当**：避免页面拥挤，保持呼吸感

### 5.2 常见问题

1. **章节过多**：控制每页目录项数量（建议6-8项）
2. **标题过长**：精简章节标题，必要时换行
3. **编号不连续**：确保章节编号连续且无重复
4. **颜色不一致**：使用预设配色方案

### 5.3 优化建议

1. **添加页码**：在目录项后添加页码
2. **图标装饰**：为每个章节添加对应的图标
3. **动画效果**：添加逐项进入动画
4. **超链接**：为目录项添加超链接，点击跳转到对应页面

## 闭环执行系统

### 1. 任务入口
- **输入**：章节列表（包含章节编号和标题）
- **前置**：
  - Python 3.8+ 已安装
  - 生成脚本 `gen_toc.py` 可用
  - 章节信息已准备
- **不适用**：
  - 章节信息未准备或不完整
  - 需要生成非目录页的其他内容
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 章节信息已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：收集章节列表信息
- **执行步骤 2**：选择模板和配色方案
- **执行步骤 3**：生成目录页PPT
- **所需工具/脚本**：`gen_toc.py`、python-pptx库
- **输入输出约束**：
  - 输入：章节列表（逗号分隔或JSON格式）
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含目录页）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有输入的章节项
  3. 布局符合选定的模板样式
- **失败条件**：
  1. 文件生成失败
  2. 章节项缺失或错误
  3. 布局严重错乱
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. 参数错误（章节列表格式错误）
  2. 生成脚本执行失败
  3. 模板/配色不支持
- **恢复策略**：检查参数格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如模板不存在）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（目录页）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：章节数量、模板类型、配色方案
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
