## 3. 工作流

```
章节列表 → ①选择模板 → ②配置样式 → ③生成PPT
```

### Step 1：收集目录信息

**必需信息**：
- 章节列表：包含章节编号和标题

**可选信息**：
- 页码：每个章节的起始页码
- 描述：章节简要描述

### Step 2：选择模板和配色

**模板选择原则**：
- 标准目录：通用场景
- 卡片式目录：现代风格
- 侧边栏目录：正式汇报

**配色选择原则**：
- 专业蓝：技术/业务类
- 商务灰：管理/行政类
- 活力橙：培训/宣导类

### Step 3：生成目录页

**生成脚本**：
```bash
# 使用默认模板
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则,操作步骤,业务要点" --out 目录.pptx

# 指定模板和配色
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则" --template card --preset blue --out 目录.pptx

# 完整参数
py -3 生成脚本/gen_toc.py --items "场景说明,业务规则,操作步骤" --titles "场景说明,业务规则,操作步骤" --template sidebar --preset gray --out 目录.pptx
```

## 5. 最佳实践

### 5.1 设计原则

1. **层次清晰**：通过编号、字体大小区分信息层次
2. **对齐美观**：保持元素对齐，提升可读性
3. **颜色协调**：使用统一的配色方案
4. **留白适当**：避免页面拥挤，保持呼吸感

### 5.2 常见问题

1. **章节过多**：控制每页目录项数量（建议6-8项）
2. **标题过长**：精简章节标题，必要时换行
3. **编号不连续**：确保章节编号连续且无重复
4. **颜色不一致**：使用预设配色方案

### 5.3 优化建议

1. **添加页码**：在目录项后添加页码
2. **图标装饰**：为每个章节添加对应的图标
3. **动画效果**：添加逐项进入动画
4. **超链接**：为目录项添加超链接，点击跳转到对应页面
