# Skill: operation-steps-skill

# 操作步骤页生成技能

## 1. 元数据

- **技能名称**：operation-steps-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取操作步骤，生成专业的操作指南PPT页面
- **适用场景**：柜员操作流程、智能柜员机流程、移动Pad流程

## 2. 工作流

```
Word文档 → ①提取操作步骤 → ②分组整理 → ③生成PPT页面
```

### Step 1：提取操作步骤内容

**识别关键词**：
- "步骤1""步骤2"... 
- "操作流程""办理流程"
- "柜员操作""智能柜员机""移动Pad"

**提取规则**：
1. 找到"步骤X:"标记的段落
2. 提取步骤编号和内容
3. 识别步骤中的注意事项（【注意事项】）

### Step 2：分组整理

**流程分组**：
1. **柜面办理流程**：柜员操作步骤
2. **智能柜员机流程**：自助设备操作步骤
3. **移动Pad流程**：移动端操作步骤

**输出格式**：
```json
{
  "title": "操作步骤",
  "flows": [
    {
      "name": "柜面办理流程",
      "steps": [
        {"seq": 1, "content": "柜员成功登录后，输入交易代码..."},
        {"seq": 2, "content": "成功进入交易界面，根据携带的有效证件..."}
      ],
      "notes": ["注意事项1", "注意事项2"]
    }
  ]
}
```

### Step 3：生成PPT页面

**页面布局**（每个流程一页）：
```
┌─────────────────────────────────────┐
│  柜面办理流程                         │ ← 标题栏（蓝色背景）
├─────────────────────────────────────┤
│  交易代码：036101                     │ ← 副标题/关键信息
├─────────────────────────────────────┤
│  ┌─────┐                            │
│  │  01  │ 柜员成功登录后，输入...     │ ← 步骤卡片
│  └─────┘                            │
│      ↓                              │
│  ┌─────┐                            │
│  │  02  │ 成功进入交易界面...         │
│  └─────┘                            │
│      ↓                              │
│  ...                                │
├─────────────────────────────────────┤
│  ⚠️ 注意事项：                       │ ← 注意事项区
│  • 人脸识别不通过时...               │
└─────────────────────────────────────┘
```

**配色方案**：
- 标题栏：深蓝 #1F3864，文字白色 #FFFFFF
- 步骤卡片：白色背景 #FFFFFF，蓝色边框 #2E75B6
- 步骤编号：蓝色圆形 #2E75B6，白色数字
- 注意事项：浅黄背景 #FFF2CC，深黄文字 #7F6000

## 3. 生成脚本

```bash
# 使用方法
py -3 生成脚本/gen_operation_steps.py 输入文档/操作手册.docx --out 操作步骤.pptx

# 指定流程类型
py -3 生成脚本/gen_operation_steps.py 输入文档/操作手册.docx --flow-type 柜面 --out 柜面操作.pptx

# 自定义标题
py -3 生成脚本/gen_operation_steps.py 输入文档/操作手册.docx --title "个人综合签约操作指南" --out 操作步骤.pptx
```

## 4. 样式规范

| 元素 | 字号 | 字体 | 颜色 |
|------|------|------|------|
| 页面标题 | 28pt | 微软雅黑 | 白色 |
| 流程名称 | 18pt | 微软雅黑 | 深灰 |
| 步骤编号 | 14pt | 微软雅黑 | 白色 |
| 步骤内容 | 14pt | 微软雅黑 | 深灰 |

## 闭环执行系统

### 1. 任务入口
- **输入**：Word文档（.docx格式），包含操作步骤、流程说明等章节
- **前置**：
  - 文档已存在于本地文件系统
  - Python 3.8+ 已安装
  - 生成脚本 `gen_operation_steps.py` 可用
- **不适用**：
  - 文档为PDF或图片格式
  - 文档不包含操作步骤相关章节
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 文档已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取Word文档，识别操作步骤章节
- **执行步骤 2**：提取步骤内容并分组整理
- **执行步骤 3**：生成操作步骤页PPT
- **所需工具/脚本**：`gen_operation_steps.py`、python-docx库
- **输入输出约束**：
  - 输入：Word文档路径
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含操作步骤页面）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有识别到的操作流程
  3. 步骤编号、内容、注意事项完整
- **失败条件**：
  1. 文件生成失败
  2. 未识别到操作步骤章节
  3. 步骤内容严重缺失
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. 文件读取失败（文件不存在/格式错误）
  2. 章节识别失败（未找到操作步骤）
  3. 生成脚本执行失败
- **恢复策略**：检查文件路径和格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如文档格式异常）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（操作步骤页面）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：文档路径、输出路径、识别到的流程数量、步骤数量
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
