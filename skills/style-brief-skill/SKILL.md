# Skill: style-brief-skill

# 风格简报生成技能

> 基于 jingmei-ppt 设计方法论

## 1. 元数据

- **技能名称**：style-brief-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：为PPT生成提供风格简报，让用户从"气质"层面选择风格
- **适用场景**：所有需要风格选择的PPT生成场景
- **依赖框架**：ppt-framework（公共样式库）

## 2. 设计理念

### 2.1 视觉论点（Visual Thesis）

**核心理念**：在动手设计前，用一句话定义整套幻灯片的气质，并设定一个"生产性张力"来指导设计决策。

**例子**：
- 专业蓝调：*"清晰、专业、可信赖"，张力是"严谨但不生硬"*
- 炭灰极简：*"沉稳、克制、权威"，张力是"严肃但不压抑"*

### 2.2 风格配方的系统表达

一种风格不仅仅是一组色值和字号，而是一个完整的系统：

| 维度 | 说明 |
|------|------|
| 视觉论点 | 三个形容词 + 一个生产性张力 |
| 标志性特征 | 让人一眼认出的视觉符号 |
| 常用版式 | 3-6种典型布局（silhouettes） |
| 混音控制 | 4个可调节维度，产生风格变体 |
| 失败信号 | 常见的设计陷阱和反面案例 |

## 3. 工作流

```
用户需求 → ①生成风格简报 → ②用户选择 → ③应用风格配方
```

### Step 1：生成风格简报

**输入**：
- 业务类型（操作培训/合规培训/新员工培训等）
- 受众（柜员/管理层/全员）
- 场景（正式/轻松/警示）

**输出**：
- 2-4份风格简报
- 每份包含：三个形容词 + 张力 + 适用场景

### Step 2：用户选择

**交互方式**：
```
请选择PPT风格：

1. 专业蓝调 - 清晰、专业、可信赖
   适用：操作培训、系统上线、常规业务宣贯

2. 炭灰极简 - 沉稳、克制、权威
   适用：合规培训、风控宣贯、管理层汇报

3. 温暖橙光 - 亲和、引导、鼓励
   适用：新员工培训、服务规范、全员宣贯

4. 红线警示 - 严肃、警示、不容置疑
   适用：合规红线、案例警示教育、反舞弊培训
```

### Step 3：应用风格配方

**生成脚本**：
```bash
# 列出可用风格
py -3 生成脚本/gen_style_brief.py --list

# 生成风格简报
py -3 生成脚本/gen_style_brief.py --scenario "操作培训" --out 风格简报.json

# 应用风格生成PPT
py -3 生成脚本/gen_ppt.py --style professional-blue --input 文档.docx --out PPT.pptx
```

## 4. 预设风格配方

### 4.1 专业蓝调 (professional-blue)

**视觉论点**：清晰、专业、可信赖
**张力**：严谨但不生硬

**标志性特征**：
- 蓝色主色调 + 橙色强调色
- 步骤编号圆环 motif
- 卡片式布局 + 细边框

**适用场景**：操作培训、系统上线、常规业务宣贯

### 4.2 炭灰极简 (charcoal-minimal)

**视觉论点**：沉稳、克制、权威
**张力**：严肃但不压抑

**标志性特征**：
- 深灰主色 + 琥珀黄强调色
- 侧边栏 motif + 章节编号
- 大量留白 + 极简装饰

**适用场景**：合规培训、风控宣贯、管理层汇报

### 4.3 温暖橙光 (warm-glow)

**视觉论点**：亲和、引导、鼓励
**张力**：温暖但不随意

**标志性特征**：
- 暖橙主色 + 深绿辅助色
- 圆角卡片 + 柔和阴影
- 插画风格的图标和配图

**适用场景**：新员工培训、服务规范、全员宣贯

### 4.4 红线警示 (red-alert)

**视觉论点**：严肃、警示、不容置疑
**张力**：严厉但不说教

**标志性特征**：
- 深红主色 + 黑色文字
- 印章/徽章 motif
- 对比强烈的红黑配色

**适用场景**：合规红线、案例警示教育、反舞弊培训

## 5. 混音旋钮

每套风格支持4个调节维度：

| 旋钮 | 专业蓝调 | 炭灰极简 | 温暖橙光 | 红线警示 |
|------|----------|----------|----------|----------|
| 主色调深浅 | 蓝色深浅 | 灰度深浅 | 橙色饱和度 | 红色比例 |
| 边框/圆角 | 卡片圆角 | 侧边栏宽度 | 圆角大小 | 装饰风格 |
| 装饰元素 | 装饰多少 | 留白比例 | 插画元素 | 字体粗细 |
| 信息密度 | 密度高低 | - | - | 案例呈现 |

## 6. 失败信号

### 通用失败信号
- 标题贴着第一个内容模块，缺少视觉停顿
- 各模块视觉权重相等，没有主次之分
- 底部内容戛然而止，没有收尾元素
- 装饰元素纯粹填充，不支持沟通目标

### 专属失败信号
- **专业蓝调**：所有页面都用相同布局，缺少节奏变化
- **炭灰极简**：标题主导页面，内容被压缩
- **温暖橙光**：橙色过多导致视觉疲劳
- **红线警示**：红色过多导致视觉压迫
