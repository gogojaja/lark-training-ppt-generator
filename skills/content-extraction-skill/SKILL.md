# Skill: content-extraction-skill

# 内容提炼技能

## 1. 元数据

- **技能名称**：content-extraction-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-17
- **技能定位**：从源文档提取内容，进行AI结构化提炼，生成宣讲导向的PPT大纲
- **适用场景**：文档内容提炼、宣讲大纲生成、信息密度优化
- **对应工作流**：SKILL.md Step 2（AI结构化提炼）

## 2. 工作流

```
源文档 → ①内容提取 → ②AI结构化提炼 → ③大纲生成 → ④用户确认
```

### Step 1：内容提取

**提取内容**：
1. 文档标题层级结构
2. 核心章节内容
3. 关键信息点（数字、日期、规则）
4. 操作步骤（如有）
5. 注意事项（如有）

**提取方式**：
- 自动提取：通过文档解析工具
- 手动补充：用户提供重点章节

### Step 2：AI结构化提炼

**提炼策略**（按宣讲目标分级）：

| 宣讲目标 | 信息密度策略 | 细节处理 |
|----------|-------------|---------|
| **宣贯**（知晓） | 每页1个核心结论 + 3-5个支撑点 | 详细条款下沉到备注 |
| **操作培训**（会用） | 不降级，每页保留完整操作说明 | 操作步骤、字段、注意事项全部保留 |
| **合规考点**（考核） | 提炼考点 + 红线 + 数字指标 | 详细条款作为参考页附后 |

**叙事重构**：
- **宣贯类**：背景与目的 → 核心条款 → 适用范围 → 权责划分 → 违规处理 → Q&A
- **操作培训类**：业务场景导入 → 角色与入口 → 关键操作流程 → 常见问题 → 练习
- **合规考点类**：制度要点 → 典型案例 → 红线清单 → 自测题

### Step 3：大纲生成

**输出格式**：
```text
[宣讲 PPT 标题] — [定位描述]，面向 [受众]，目标：[宣贯/培训/考核]

页面结构（N 页）：
1. 封面页：[标题] | [副标题/宣讲场景]
2. 目录页：[分节列表]
3. 场景说明：[场景定义] | [适用范围] | [渠道对比]
4. 操作介绍：[完整业务流程概述]
5. 职能流程图：[角色分工泳道图]
6. 柜面操作总览：[交易代码] | [权限] | [步骤总览]
7. 步骤1-2：[操作说明] | [关键字段] | [注意事项]
...
N. 结尾页：[行动指引 / 速查表 / Q&A]

风格：[配色方案]，[排版风格]
内容深度：[每页四要素覆盖情况]
注意事项覆盖：[列出每个步骤的注意事项来源]

事实校验批注：
- [信息点1]: [置信度] [校验结果]
- [信息点2]: [置信度] [校验结果]
```

### Step 4：用户确认

**确认内容**：
1. 大纲结构是否符合预期
2. 信息密度是否合适
3. 是否需要调整页面顺序
4. 是否需要补充/删减内容

**确认后**：进入 Step 3（风格样例预览）

## 3. 生成脚本

```bash
# 提取文档结构
py -3 生成脚本/extract_content.py input.docx --out content.json

# 生成大纲
py -3 生成脚本/generate_outline.py content.json --target training --out outline.json

# 生成宣讲大纲文档
py -3 生成脚本/create_outline_doc.py outline.json --out 宣讲大纲.md
```

## 4. 信息密度规范

### 4.1 宣贯类（知晓）
- 每页1个核心结论
- 3-5个支撑点
- 详细条款下沉到备注
- 页数：15-20页

### 4.2 操作培训类（会用）
- 不降级，完整保留操作说明
- 每步包含四要素：操作说明 + 关键字段 + 注意事项 + 易错点
- 页数：按操作步骤数量

### 4.3 合规考点类（考核）
- 提炼考点 + 红线 + 数字指标
- 典型案例
- 自测题
- 页数：20-30页

## 闭环执行系统

### 1. 任务入口
- **输入**：源文档（Word/PDF/飞书文档URL）
- **前置**：
  - 文档已准备好或URL可访问
  - 用户已确认宣讲目标和受众
- **不适用**：
  - 文档内容为空或无法读取
  - 用户未明确宣讲目标

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 文档已准备且用户已确认目标 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 大纲已生成 | 通过/失败 | 检查大纲质量 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 用户确认通过 | 进入风格预览 | 归档证据与输出 |
| 回退 | 执行失败/用户拒绝 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取源文档，提取内容结构
- **执行步骤 2**：按宣讲目标进行AI结构化提炼
- **执行步骤 3**：生成宣讲大纲
- **执行步骤 4**：提交用户确认
- **所需工具/脚本**：`extract_content.py`、`generate_outline.py`
- **输入输出约束**：
  - 输入：源文档路径/URL、宣讲目标、受众
  - 输出：大纲文档（Markdown/JSON）

### 4. 验收门禁
- **必须产出物**：宣讲大纲文档
- **通过条件**：
  1. 大纲结构完整（封面/目录/内容/结尾）
  2. 信息密度符合宣讲目标
  3. 用户确认通过
- **失败条件**：
  1. 大纲结构不完整
  2. 信息密度不符合要求
  3. 用户拒绝确认
- **审核对象**：用户

### 5. 失败处理
- **失败类型**：
  1. 文档读取失败
  2. 内容提取失败
  3. 大纲生成失败
  4. 用户拒绝确认
- **恢复策略**：检查文档可读性，调整提炼策略
- **回滚方案**：删除生成的大纲，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：所有场景都需要用户确认

### 6. 产出与交接
- **产出物列表**：宣讲大纲文档
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/风格预览技能
- **下一步动作**：进入风格样例预览（Step 3）
- **归档条件**：用户确认通过

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：文档路径、宣讲目标、受众、页面数量
- **关键决策**：用户确认结果、信息密度选择
- **结果证据**：生成的大纲文档路径
- **失败原因**：记录失败类型和详细信息
