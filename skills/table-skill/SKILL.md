# Skill: table-skill

# 表格页生成技能

## 1. 元数据

- **技能名称**：table-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：生成专业的PPT表格页，展示结构化数据
- **适用场景**：数据对比、规则说明、配置参数、收费标准

### 2.2 配色方案

**专业蓝（默认）**：
- 表头背景：#1F3864（深蓝）
- 表头文字：#FFFFFF（白色）
- 数据行背景：#FFFFFF（白色）
- 斑马纹背景：#F8FAFC（浅灰）
- 边框颜色：#E0E0E0（浅灰）
- 强调色：#2E75B6（中蓝）

**商务灰**：
- 表头背景：#404040（深灰）
- 表头文字：#FFFFFF（白色）
- 数据行背景：#FFFFFF（白色）
- 斑马纹背景：#F5F5F5（浅灰）
- 边框颜色：#E0E0E0（浅灰）
- 强调色：#808080（中灰）

**语义色**：
- 成功/通过：#006100（绿色）
- 警告/注意：#7F6000（黄色）
- 错误/禁止：#C00000（红色）
- 信息/提示：#2E75B6（蓝色）

## 3. 工作流

```
Word文档 → ①提取表格数据 → ②选择模板和配色 → ③生成PPT
```

### Step 1：提取表格数据

从 Word 文档提取表格数据并保存为 JSON 格式：

```bash
py -3 extract_table_data.py
```

**数据格式**：
```json
{
  "title": "预约查询 - 高拍仪品牌配置表",
  "headers": ["高拍仪品牌", "转换值", "分辨率", "DPI转换值", "色彩", "裁剪方式", "旋转"],
  "rows": [
    ["升腾", "219", "2592*1944", "200", "彩色", "自动寻边纠偏", "旋转度可自由调配，需保证拍摄影像端正"],
    ["实达", "221", "2592*1944", "200", "彩色", "自动寻边纠偏", ""],
    ["国光", "224", "2592*1944", "200", "彩色", "自动寻边纠偏", ""]
  ]
}
```

### Step 2：选择模板和配色

**模板选择原则**：
- 标准表格：通用场景
- 斑马纹表格：数据较多时
- 带图标表格：需要状态标识时

**配色选择原则**：
- 专业蓝：技术/业务类
- 商务灰：管理/行政类

### Step 3：生成表格页

**生成脚本**：
```bash
# 使用默认模板
py -3 生成脚本/gen_table.py "生成产物/表格/预约查询.json"

# 指定模板和配色
py -3 生成脚本/gen_table.py "生成产物/表格/预约查询.json" zebra blue

# 自定义输出文件名
py -3 生成脚本/gen_table.py "生成产物/表格/预约查询.json" standard blue "我的表格.pptx"
```

**实际案例**：
```bash
# 生成预约查询表格（斑马纹模板 + 专业蓝配色）
py -3 生成脚本/gen_table.py "生成产物/表格/预约查询.json" zebra blue "预约查询表格.pptx"
```

## 5. 最佳实践

### 5.1 设计原则

1. **对齐美观**：保持表格元素对齐
2. **颜色协调**：使用统一的配色方案
3. **层次清晰**：通过表头、斑马纹区分信息层次
4. **留白适当**：避免表格过于拥挤

### 5.2 常见问题

1. **列宽不均**：合理分配列宽
2. **文字溢出**：控制文本长度，必要时换行
3. **颜色不协调**：使用预设配色方案
4. **数据不清晰**：使用斑马纹或图标增强可读性

### 5.3 优化建议

1. **添加图标**：为状态字段添加图标
2. **条件格式**：根据数据值改变颜色
3. **排序功能**：支持按列排序
4. **导出功能**：支持导出为Excel

## 闭环执行系统

### 1. 任务入口
- **输入**：JSON格式的表格数据（包含标题、表头、数据行）
- **前置**：
  - Python 3.8+ 已安装
  - 生成脚本 `gen_table.py` 可用
  - 表格数据已准备为JSON格式
- **不适用**：
  - 表格数据未准备或格式错误
  - 需要生成非表格页的其他内容
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 数据已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取JSON格式的表格数据
- **执行步骤 2**：选择模板和配色方案
- **执行步骤 3**：生成表格页PPT
- **所需工具/脚本**：`gen_table.py`、python-pptx库
- **输入输出约束**：
  - 输入：JSON文件路径
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含表格页）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有输入的数据行
  3. 表头、数据行、边框格式正确
- **失败条件**：
  1. 文件生成失败
  2. 数据行缺失或错误
  3. 表格格式严重错乱
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. JSON格式错误
  2. 生成脚本执行失败
  3. 模板/配色不支持
- **恢复策略**：检查JSON格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如数据格式异常）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（表格页）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：数据行数、列数、模板类型、配色方案
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
