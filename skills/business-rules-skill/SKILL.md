# Skill: business-rules-skill

# 业务规则页生成技能

## 1. 元数据

- **技能名称**：business-rules-skill
- **技能版本**：v1.0.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取业务规则和限制条件，生成专业的规则说明PPT页面
- **适用场景**：业务限制、办理条件、禁止事项、审批要求

## 2. 工作流

```
Word文档 → ①提取业务规则 → ②分类整理 → ③生成PPT页面
```

### Step 1：提取业务规则内容

**识别关键词**：
- "不允许""禁止""不得"
- "必须""需要""要求"
- "限制""条件""前提"
- "注意事项""重要提醒"
- "审批""审核""授权"

**提取规则**：
1. 找到规则相关段落
2. 保留编号和层级结构
3. 识别规则类型（限制/要求/审批）

### Step 2：分类整理

**规则分类**：
1. **限制类规则**：不允许办理的情况
2. **要求类规则**：必须满足的条件
3. **审批类规则**：需要上级授权的情况
4. **默认规则**：系统默认设置

**输出格式**：
```json
{
  "title": "业务规则",
  "subtitle": "办理条件与限制",
  "rules": [
    {
      "type": "restriction",
      "items": [
        "不允许代理",
        "身份证件过期不允许办理",
        "涉案账户不允许办理"
      ]
    },
    {
      "type": "requirement",
      "items": [
        "需要有效身份证件",
        "需要人脸识别通过"
      ]
    }
  ]
}
```

### Step 3：生成PPT页面

**页面布局**：
```
┌─────────────────────────────────────┐
│  业务规则                            │ ← 标题栏（红色背景）
├─────────────────────────────────────┤
│  办理条件与限制                       │ ← 副标题
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐   │
│  │ 🚫 限制类规则                │   │ ← 限制类（红色标记）
│  │  • 不允许代理                │   │
│  │  • 身份证件过期不允许办理     │   │
│  ├─────────────────────────────┤   │
│  │ ✅ 要求类规则                │   │ ← 要求类（绿色标记）
│  │  • 需要有效身份证件           │   │
│  │  • 需要人脸识别通过           │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

**配色方案**：
- 标题栏：深红 #C00000，文字白色 #FFFFFF
- 限制类规则：浅红背景 #FCE4EC，红色标记 #C00000
- 要求类规则：浅绿背景 #E2EFDA，绿色标记 #006100
- 审批类规则：浅黄背景 #FFF2CC，黄色标记 #7F6000

## 3. 生成脚本

```bash
# 使用方法
py -3 生成脚本/gen_business_rules.py 输入文档/操作手册.docx --out 业务规则.pptx

# 自定义标题
py -3 生成脚本/gen_business_rules.py 输入文档/操作手册.docx --title "签约业务规则" --out 业务规则.pptx
```

## 4. 样式规范

| 元素 | 字号 | 字体 | 颜色 |
|------|------|------|------|
| 页面标题 | 28pt | 微软雅黑 | 白色 |
| 副标题 | 18pt | 微软雅黑 | 深灰 |
| 规则分类标题 | 16pt | 微软雅黑 | 对应颜色 |
| 规则内容 | 14pt | 微软雅黑 | 深灰 |
| 规则标记 | 14pt | Segoe UI Emoji | 对应颜色 |
