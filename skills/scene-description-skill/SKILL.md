# Skill: scene-description-skill

# 场景说明页生成技能

## 1. 元数据

- **技能名称**：scene-description-skill
- **技能版本**：v1.1.0
- **发布日期**：2026-08-12
- **技能定位**：从 Word 文档提取场景说明内容，生成专业的场景说明PPT页面
- **适用场景**：业务背景介绍、功能概述、服务范围说明
- **依赖框架**：ppt-framework（公共样式库）

## 3. 工作流

```
Word文档 → ①提取场景说明 → ②内容结构化 → ③生成PPT页面
```

### Step 1：提取场景说明内容

**识别关键词**：
- "场景说明"
- "业务背景"
- "功能介绍"
- "服务范围"
- "业务概述"

**提取规则**：
1. 找到"场景说明"标记后，提取后续段落直到遇到下一个章节标记
2. 保留原始段落结构，不要合并
3. 过滤空行和无效内容

### Step 2：内容结构化

**分类处理**：
1. **功能列表**：以"提供""支持""开通""修改""关闭"开头的段落
2. **服务项目**：具体的服务名称（如"非柜面限额""快捷支付"等）
3. **补充说明**：其他描述性内容

**输出格式**：
```json
{
  "title": "场景说明",
  "subtitle": "业务背景与功能介绍",
  "sections": [
    {
      "type": "overview",
      "content": "本场景提供以下渠道..."
    },
    {
      "type": "features",
      "items": ["非柜面限额", "快捷支付", "互联网数字银行", ...]
    }
  ]
}
```

### Step 3：生成PPT页面

**生成脚本**：
```bash
# 使用默认模板
py -3 生成脚本/gen_scene_description.py 输入文档/操作手册.docx --out 场景说明.pptx

# 指定模板和配色
py -3 生成脚本/gen_scene_description.py 输入文档/操作手册.docx --template card --preset blue --out 场景说明.pptx

# 自定义标题
py -3 生成脚本/gen_scene_description.py 输入文档/操作手册.docx --title "个人综合签约业务介绍" --out 场景说明.pptx
```

## 5. 最佳实践

### 5.1 设计原则

1. **层次清晰**：通过标题、副标题、正文区分信息层次
2. **颜色协调**：使用统一的配色方案
3. **留白适当**：避免页面拥挤，保持呼吸感
4. **对齐美观**：保持元素对齐，提升可读性

### 5.2 常见问题

1. **内容过长**：精简内容，突出重点
2. **文字溢出**：控制文本长度，必要时换行
3. **颜色不协调**：使用预设配色方案
4. **布局混乱**：遵循网格对齐原则

### 5.3 优化建议

1. **添加图标**：为功能列表添加图标
2. **分栏布局**：使用分栏布局提升可读性
3. **动画效果**：添加简单的进入动画
4. **超链接**：为功能项添加超链接

## 闭环执行系统

### 1. 任务入口
- **输入**：Word文档（.docx格式），包含场景说明、业务背景、功能介绍等章节
- **前置**：
  - 文档已存在于本地文件系统
  - Python 3.8+ 已安装
  - 生成脚本 `gen_scene_description.py` 可用
- **不适用**：
  - 文档为PDF或图片格式
  - 文档不包含场景说明相关章节
  - 需要联网获取外部数据

### 2. 执行状态
| 状态 | 进入条件 | 退出条件 | 处理方式 |
|------|---------|---------|---------|
| 待启动 | 文档已准备且前置条件满足 | 用户确认/系统启动 | 准备上下文与输入 |
| 执行中 | 任务已启动 | 关键动作完成或失败 | 按步骤执行 |
| 校验中 | 关键动作完成 | 通过/失败 | 检查门禁与中间产出 |
| 阻塞 | 依赖缺失/信息不足 | 补充信息/人工处理 | 暂停推进并记录原因 |
| 完成 | 验收通过 | 进入交接 | 归档证据与输出 |
| 回退 | 执行失败/门禁未过 | 回到最近稳定状态 | 回滚与复盘 |

### 3. 执行动作层
- **执行步骤 1**：读取Word文档，识别场景说明章节
- **执行步骤 2**：提取内容并结构化整理
- **执行步骤 3**：生成场景说明页PPT
- **所需工具/脚本**：`gen_scene_description.py`、python-docx库
- **输入输出约束**：
  - 输入：Word文档路径
  - 输出：PPTX文件（默认当前目录）

### 4. 验收门禁
- **必须产出物**：PPTX文件（包含场景说明页面）
- **通过条件**：
  1. 文件成功生成且可正常打开
  2. 包含所有识别到的场景说明内容
  3. 布局符合选定的模板样式
- **失败条件**：
  1. 文件生成失败
  2. 未识别到场景说明章节
  3. 内容严重缺失
- **审核对象**：用户/系统

### 5. 失败处理
- **失败类型**：
  1. 文件读取失败（文件不存在/格式错误）
  2. 章节识别失败（未找到场景说明）
  3. 生成脚本执行失败
- **恢复策略**：检查文件路径和格式，重新执行
- **回滚方案**：删除生成的错误文件，恢复原始状态
- **重试策略**：修正问题后可重试最多3次
- **是否需要人工确认**：高危场景（如文档格式异常）需要人工确认

### 6. 产出与交接
- **产出物列表**：PPTX文件（场景说明页面）
- **保存路径**：当前工作目录或指定输出路径
- **交接对象**：用户/下游技能（如PPT合并）
- **下一步动作**：可选择继续生成其他页面或导出最终PPT
- **归档条件**：文件生成成功且通过验收

### 7. 审计记录
- **执行时间**：记录开始和结束时间
- **关键参数**：文档路径、输出路径、识别到的内容段落数
- **关键决策**：是否通过验收、是否回退
- **结果证据**：生成的PPTX文件路径
- **失败原因**：记录失败类型和详细信息
