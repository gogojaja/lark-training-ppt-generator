flowchart-skill 是一个用于 flowchart skill 的技能包。

## 使用方法

### 安装

```bash
# 克隆仓库
git clone <repository-url>

# 安装依赖
pip install -r requirements.txt
```

### 基础使用

```python
from flowchart_skill import SkillClass

skill = SkillClass()
result = skill.execute()
print(result)
```

### 高级使用

```python
from flowchart_skill import AdvancedSkill

skill = AdvancedSkill()
skill.configure(param1='value1')
result = skill.process()
print(result)
```

## 配置

### 配置文件

```json
{
  "param1": "value1",
  "param2": "value2"
}
```

### 环境变量

- `SKILL_PARAM1`: 参数1的值
- `SKILL_PARAM2`: 参数2的值
