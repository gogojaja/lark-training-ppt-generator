# PPT 技能提升方案

从「自己写的脚本效果一般」到「接近精美 PPT / 豆包水平」的完整方法论与代码示例。

## 📁 文件清单

| 文件 | 说明 |
|------|------|
| `PPT技能提升方案.html` | 完整提升方案文档（可直接在浏览器打开阅读） |
| `theme.js` | 浅绿色主题设计令牌（颜色/字体/尺寸/间距/角色色板） |
| `mint-theme-example.js` | 三页 PPT 示例代码（封面+目录+泳道流程图） |

## 🚀 快速开始

### 1. 阅读提升方案
直接用浏览器打开 `PPT技能提升方案.html`

### 2. 运行示例代码

```bash
# 安装依赖
npm install pptxgenjs

# 生成 PPT
node mint-theme-example.js
```

生成文件：`浅绿色主题示例.pptx`

## 🎯 核心架构

```
设计令牌 (theme.js)
    │
    ├── color       颜色令牌（按角色命名）
    ├── typography  字体令牌（按层级命名）
    ├── size        尺寸令牌（画布/间距/组件尺寸）
    ├── spacing     间距令牌（三级尺度）
    ├── roleColors  角色色板（泳道/分类用）
    └── components  组件默认配置
    │
基础组件库 (mint-theme-example.js 中)
    ├── addHeader()      统一页眉
    ├── addFooter()      统一页脚
    └── addInfoCard()    信息卡片
    │
页面组合函数
    ├── slideCover()     封面页
    ├── slideToc()       目录页
    └── slideSwimlane()  职能流程图页
    │
buildPPT() —— 组装入口
```

## 📋 提升方案 6 步法

1. **建立角色化设计令牌系统** — 颜色/字号/间距都按角色命名
2. **封装基础组件库** — 页眉、页脚、卡片、徽章等统一封装
3. **建立内容类型→页面轮廓映射** — 不同内容选不同布局
4. **建立垂直节奏规范** — 六段式页面结构
5. **加入风格配方系统** — 多套风格切换
6. **加入质量检查环节** — 结构检查+视觉检查+程序化检测

## 🎨 浅绿色主题配色

- **主色**：柔和中绿 `#27AE60`
- **背景**：极浅绿 `#F5FFF7`（护眼）
- **辅色**：天蓝 `#5DADE2`、暖黄 `#F4D03F`、浅紫 `#AF7AC5`
- **状态色**：浅绿（成功）、暖橙（警告）、浅红（风险）
- **深色块**：深绿 `#1E5631`（封面/结束页）

## 💡 快速见效的 3 件事

1. 抽出统一的 `header` + `footer` 组件
2. 定义颜色角色令牌，删掉所有硬编码颜色
3. 做 3 种页面轮廓模板（列表页/表格页/卡片网格页）
