# PPTX 生成模板使用说明

## 快速开始

1. 打开 `generate-pptx-template.ps1`
2. 修改 `$slides` 数据数组（替换为你的内容）
3. 修改 `$outFile` 输出路径
4. 运行脚本

## 数据格式

每张幻灯片是一个哈希表，`type` 字段决定布局：

```
封面页:  @{type="cover";   title="大标题"; sub="副标题"; notes="讲者备注"}
章节页:  @{type="section"; title="章节标题"; sub="章节副标题"; notes="讲者备注"}
文字页:  @{type="text";    title="标题"; content="正文内容"; notes="讲者备注"}
双栏页:  @{type="2col";    title="标题"; left="左栏(首行为标题)"; right="右栏(首行为标题)"; notes="讲者备注"}
```

换行用 `` `n ``（反引号+n）。双栏页的左/右栏首行会自动加粗作为小标题。

## 颜色定制

修改 `$col` 哈希表即可换肤。当前为浅绿色系：

| 变量 | 当前值 | 用途 |
|------|--------|------|
| slideBg | FAFDFB | 内容页背景（近白） |
| coverBg | F0F7F2 | 封面背景（浅绿） |
| sectionBg | E8F5E9 | 章节页背景（淡绿） |
| cardBg | FFFFFF | 卡片背景（白色） |
| title | 1B5E20 | 标题文字（深绿） |
| body | 37474F | 正文文字（深灰） |
| accent | 66BB6A | 强调色/装饰条 |

换色示例（蓝色系）：
```powershell
$col = @{
    slideBg="F8FAFC"; coverBg="EFF6FF"; sectionBg="DBEAFE"
    cardBg="FFFFFF"; title="1E40AF"; body="37474F"
    subtitle="3B82F6"; muted="93C5FD"; accent="3B82F6"
    border="BFDBFE"; decoCircle="DBEAFE"
}
```

## 已固化的经验（避免重复踩坑）

以下是在开发过程中通过反复试错发现的问题和解决方案，已固化到模板中：

### 1. WPS COM 初始化（最关键的坑）
- **问题**: `New-Object -ComObject PowerPoint.Application` 报错 `80010001 Call was rejected by callee`
- **原因**: WPS 演示的 COM 注册 LocalServer32 值为空，无法创建新实例
- **解决**: 先杀旧 wpp.exe 进程 → 用 Start-Process 启动新实例 → 等 15 秒 → 用 `GetActiveObject` 连接
- **代码位置**: 主执行部分

### 2. 幻灯片布局
- **问题**: Layout 12 (ppLayoutBlank) 在 WPS 中不工作，返回 null
- **解决**: 用 Layout 1 (ppLayoutTitle)，然后清除默认占位符文字
- **代码位置**: `RenderSlide` 函数开头

### 3. 函数命名
- **问题**: 函数名 `R`、`FT`、`NT`、`WL` 与 PowerShell 内置别名冲突
- **解决**: 使用完整名称 `GetRGB`、`SetFooter`、`SetNotes`、`WriteLog`

### 4. 文件编码
- **问题**: 中文乱码
- **解决**: 脚本必须用 UTF-8 BOM 编码保存
- **方法**: `[System.IO.File]::WriteAllText($path, $content, [System.Text.Encoding]::UTF8)`

### 5. COM 调用频率
- **问题**: 快速连续 COM 调用会被 WPS 拒绝（RPC_E_CALL_REJECTED）
- **解决**: 每页幻灯片之间加 300ms 延迟

### 6. PageSetup
- **问题**: `$pres.PageSetup.SlideWidth` 在 WPS 中可能不可用
- **解决**: 用 try-catch 包裹，失败时使用默认尺寸

### 7. 字体大小类型
- **问题**: 整数赋值给 Font.Size 可能失败
- **解决**: 必须用 `[float]` 强制转换

### 8. 颜色格式
- **问题**: PowerPoint COM 使用 BGR 格式，不是 RGB
- **解决**: `GetRGB` 函数将十六进制颜色转为 BGR 整数

## 如何减少 Token 消耗

下次生成 PPT 时，只需要：
1. 复制模板文件
2. 替换 `$slides` 数据（这是唯一需要修改的部分）
3. 修改 `$col` 颜色（可选）
4. 修改 `$outFile` 路径（可选）

不需要重新编写渲染逻辑、辅助函数、COM 初始化代码。
预计可减少 70%+ 的 token 消耗。

## 形状常量速查

| 常量 | 值 | 形状 |
|------|----|------|
| msoShapeRectangle | 1 | 矩形 |
| msoShapeRoundedRectangle | 5 | 圆角矩形 |
| msoShapeOval | 9 | 椭圆/圆形 |

| 常量 | 值 | 对齐 |
|------|----|------|
| ppAlignLeft | 1 | 左对齐 |
| ppAlignCenter | 2 | 居中 |
| ppAlignRight | 3 | 右对齐 |

| 常量 | 值 | 布局 |
|------|----|------|
| ppLayoutTitle | 1 | 标题页 |
| ppLayoutText | 2 | 文字页 |
| ppLayoutBlank | 12 | 空白页(WPS不支持) |
