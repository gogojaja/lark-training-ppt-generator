## 开发标准

### 1. 目录结构

所有技能包必须遵循以下标准目录结构：

```
skill-name/
├── SKILL.md              # 技能元数据
├── SKILL_INDEX.md        # 技能索引
├── README.md             # 使用说明
├── templates/            # 模板文件
│   └── template_example.txt
├── styles/               # 样式定义
│   └── style_example.css
└── examples/             # 示例代码
    └── example.py
```

**要求**:
- `templates/` 目录必须存在
- `styles/` 目录必须存在
- `examples/` 目录必须存在
- `SKILL_INDEX.md` 必须存在
- `README.md` 必须存在
- `SKILL.md` 必须存在（除 ppt-framework 外）

### 2. 文件命名

**要求**:
- 使用小写字母和下划线：`skill_name.py`
- 避免使用空格和特殊字符
- 使用有意义的名称：`create_cover_page.py` 而不是 `c.py`

### 3. 代码组织

**要求**:
- 按功能模块组织代码
- 使用清晰的函数命名
- 添加适当的注释
- 遵循单一职责原则

## 代码规范

### 1. Python代码规范

**PEP 8 标准**:
- 使用4个空格缩进
- 每行不超过79个字符
- 函数和类使用大写字母开头
- 使用下划线命名私有方法

**示例**:
```python
def create_cover_page(pres, title, subtitle, author, date):
    """创建封面页

    Args:
        pres: Presentation对象
        title: 演示主题
        subtitle: 副标题
        author: 作者
        date: 日期

    Returns:
        Slide对象
    """
    # 实现代码
    pass
```

### 2. 注释规范

**要求**:
- 函数必须有文档字符串
- 复杂逻辑必须有注释
- 使用中文注释（如果面向中文用户）

**示例**:
```python
def calculate_discount(price, discount_rate):
    """计算折扣价格

    Args:
        price: 原价
        discount_rate: 折扣率（0-1）

    Returns:
        折扣后价格
    """
    if discount_rate < 0 or discount_rate > 1:
        raise ValueError("折扣率必须在0-1之间")

    return price * (1 - discount_rate)
```

### 3. 错误处理

**要求**:
- 检查参数有效性
- 提供有意义的错误信息
- 使用try-except处理异常

**示例**:
```python
def create_table(pres, title, columns, rows):
    """创建表格

    Args:
        pres: Presentation对象
        title: 表格标题
        columns: 列名列表
        rows: 数据行列表

    Raises:
        ValueError: 如果参数无效
    """
    if not columns:
        raise ValueError("列名不能为空")

    if not rows:
        raise ValueError("数据行不能为空")

    try:
        # 创建表格
        pass
    except Exception as e:
        raise RuntimeError(f"创建表格失败: {e}")
```

### 4. 命名规范

**函数命名**:
- 使用动词开头：`create_`, `get_`, `set_`
- 使用清晰的名字：`create_cover_page` 而不是 `create1`

**变量命名**:
- 使用小写字母和下划线：`table_title`
- 使用有意义的名字：`customer_name` 而不是 `name`

**常量命名**:
- 使用大写字母和下划线：`MAX_WIDTH`
- 使用有意义的名字：`DEFAULT_FONT_SIZE` 而不是 `DEFAULT`

## 测试规范

### 1. 单元测试

**要求**:
- 测试所有公共函数
- 测试边界条件
- 测试错误处理
- 测试覆盖率 > 80%

**示例**:
```python
import unittest
from skill_name import SkillClass

class TestSkillClass(unittest.TestCase):
    def setUp(self):
        self.skill = SkillClass()

    def test_basic_function(self):
        result = self.skill.execute()
        self.assertIsNotNone(result)

    def test_invalid_param(self):
        with self.assertRaises(ValueError):
            self.skill.execute(invalid_param='value')

if __name__ == '__main__':
    unittest.main()
```

## 发布规范

### 1. 版本号

**格式**: `v主版本.次版本.修订版本`

**规则**:
- 主版本：不兼容的API修改
- 次版本：向后兼容的功能添加
- 修订版本：向后兼容的问题修复

**示例**:
- v1.0.0: 初始版本
- v1.1.0: 添加新功能
- v1.1.1: 修复bug
