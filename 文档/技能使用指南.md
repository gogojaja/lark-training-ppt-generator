## 快速开始

### 1. 安装依赖

```bash
# 安装 Python 依赖
pip install python-pptx openpyxl
```

### 2. 创建演示文稿

```python
from pptx import Presentation

# 创建演示文稿
pres = Presentation()
```

### 3. 使用技能包

```python
from cover_skill import create_cover_page
from toc_skill import create_toc_page

# 添加封面页
create_cover_page(pres, '标题', '副标题', '作者', '日期')

# 添加目录页
create_toc_page(pres, '目录', ['项1', '项2', '项3'])

# 保存
pres.save('output.pptx')
```

## 技能包列表

### 封面页技能包 (cover-skill)

**用途**: 创建专业PPT封面页

**核心功能**:
- 标准封面页生成
- 自定义配色方案
- 支持作者和日期

**使用示例**:
```python
from cover_skill import create_cover_page

slide = create_cover_page(
    pres,
    title='个人综合签约培训',
    subtitle='操作流程与注意事项',
    author='培训部',
    date='2026-08-13'
)
```

**参数说明**:
- `title`: 演示主题
- `subtitle`: 副标题
- `author`: 作者/团队名称
- `date`: 日期

**样式配置**:
```python
# 在 styles/style_example.css 中配置
--cover-primary: #1F3864;      /* 主色调 */
--cover-secondary: #2E75B6;    /* 辅助色 */
--cover-accent: #ED7D31;       /* 强调色 */
```

```python
from pptx import Presentation
```

### 批量生成多个PPT

```python
import os
from pathlib import Path
from pptx import Presentation
from cover_skill import create_cover_page
from toc_skill import create_toc_page

# 定义培训主题
trainings = [
    {
        'title': '个人综合签约培训',
        'subtitle': '操作流程与注意事项',
        'author': '培训部',
        'date': '2026-08-13',
        'toc_items': [
            '个人综合签约概述 - 第1-2页',
            '签约流程详解 - 第3-8页',
            '注意事项 - 第9-12页',
            '常见问题 - 第13-15页'
        ]
    },
    {
        'title': '客户服务培训',
        'subtitle': '服务标准与规范',
        'author': '客户服务部',
        'date': '2026-08-13',
        'toc_items': [
            '服务概述 - 第1-2页',
            '服务标准 - 第3-5页',
            '常见问题 - 第6-8页'
        ]
    }
]

# 批量生成
output_dir = Path('output')
output_dir.mkdir(exist_ok=True)

for training in trainings:
    pres = Presentation()

    # 添加封面页
    create_cover_page(
        pres,
        title=training['title'],
        subtitle=training['subtitle'],
        author=training['author'],
        date=training['date']
    )

    # 添加目录页
    create_toc_page(pres, '目录', training['toc_items'])

    # 保存
    filename = f"{training['title']}.pptx"
    output_path = output_dir / filename
    pres.save(output_path)
    print(f"已生成: {output_path}")

print(f"\n批量生成完成！共生成 {len(trainings)} 个PPT文件")
```

### 自定义样式

```python
from pptx import Presentation
from pptx.util import Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

# 创建演示文稿
pres = Presentation()

# 自定义样式
primary_color = RGBColor(31, 56, 100)  # 深蓝色
secondary_color = RGBColor(46, 117, 182)  # 中蓝色
accent_color = RGBColor(237, 125, 49)  # 橙色

# 创建标题
title_box = pres.slides[0].shapes.add_textbox(
    Inches(1), Inches(2), Inches(8), Inches(1)
)
title_frame = title_box.text_frame
title_frame.text = '个人综合签约培训'
title_frame.paragraphs[0].font.size = Pt(48)
title_frame.paragraphs[0].font.bold = True
title_frame.paragraphs[0].font.color.rgb = primary_color
title_frame.paragraphs[0].alignment = PP_ALIGN.CENTER

# 保存
pres.save('output/custom_style.pptx')
```

## 最佳实践

### 1. 结构规划

- **封面页**: 清晰展示培训主题
- **目录页**: 展示内容结构
- **内容页**: 按逻辑顺序组织
- **总结页**: 总结关键信息
- **FAQ页**: 回答常见问题

### 2. 样式一致性

- 使用统一的配色方案
- 保持一致的字体大小
- 使用统一的间距
- 保持一致的排版风格

### 3. 内容简洁

- 每页不超过5个要点
- 使用清晰的标题
- 适当使用图表和表格
- 避免文字过多

### 4. 交互性

- 使用动画效果
- 添加超链接
- 使用多媒体

### 5. 可访问性

- 使用清晰的字体
- 保持足够的对比度
- 提供文字描述

## 常见问题

### Q1: 如何修改技能包的样式？

**A**: 在技能包的 `styles/` 目录中找到对应的样式文件，修改颜色、字体、间距等配置。

### Q2: 如何创建自定义的页面类型？

**A**:
1. 在技能包的 `templates/` 目录中创建模板文件
2. 在 `examples/` 目录中创建示例代码
3. 在 `SKILL.md` 中记录使用方法

### Q3: 如何添加新的技能包？

**A**:
1. 在 `skills/` 目录下创建新的技能包文件夹
2. 添加标准目录结构（templates/, styles/, examples/）
3. 创建 SKILL_INDEX.md 和 README.md
4. 在 `skills/SKILL_INDEX.md` 中添加技能包信息

### Q4: 如何批量生成PPT？

**A**: 使用批量生成示例中的代码，定义培训主题列表，循环生成每个PPT。

### Q5: 如何处理Word文档？

**A**: 使用 `document-processing` 技能包，提供多种拆分和转换功能。
