# 文档管理规范

## 概述

本文档规范了 lark-training-ppt-generator 项目的文档管理结构，确保各个技能的过程产物和最终产物有清晰的存放位置。

## 目录结构规范

### 1. 根目录

```
lark-training-ppt-generator/
├── .lark-internal/          # Lark 内部配置
├── .lark-slides/            # Lark 幻灯片配置
├── .trae-html-share-packages/  # HTML 分享包
├── dist/                    # 构建产物（前端）
├── skills/                  # 技能包目录
├── tools/                   # 工具脚本
├── 文档/                    # 项目文档
├── 输入文档/                # 输入文档
├── 生成脚本/                # 生成脚本
├── 生成产物/                # 生成产物
└── 输出文档/                # 输出文档
```

### 2. 各目录职责

#### 2.1 输入文档/ (Input Documents)

**职责**：存放原始输入文件

**内容**：
- `个人综合签约.docx` - 主要输入文档
- `个人综合签约_拆分.docx` - 拆分后的输入文档
- `个人客户信息维护.docx` - 其他输入文档
- `预约查询.docx` - 其他输入文档

**文件命名**：
- 使用中文命名，清晰描述文档内容
- 保持原文件格式（.docx）

#### 2.2 生成脚本/ (Generation Scripts)

**职责**：存放所有生成脚本

**内容**：
- `generate_page.py` - 主页生成脚本
- `gen_table.py` - 表格页生成脚本
- `extract_table_data.py` - 表格数据提取脚本
- `csv_to_flowchart.py` - 流程图生成脚本
- `gen_flowchart.py` - 流程图生成脚本
- 其他生成脚本...

**文件命名**：
- 使用小写字母，下划线分隔
- 清晰描述功能（gen_xxx.py, extract_xxx.py）

#### 2.3 生成产物/ (Generated Artifacts)

**职责**：存放所有生成的中间产物和最终产物

**子目录**：

##### 2.3.1 生成产物/拆分/
**职责**：存放拆分后的文档

**内容**：
- `个人综合签约_拆分.docx` - 拆分后的文档
- `新场景操作手册_拆分/` - 新场景操作手册拆分目录
  - `个人客户信息维护.docx`
  - `预约查询.docx`
  - 其他场景文档...

##### 2.3.2 生成产物/表格/
**职责**：存放表格相关的生成产物

**内容**：
- `.json` - 表格数据源文件
- `*.pptx` - 表格页 PPT 文件

**示例**：
- `生成产物/表格/账户修改功能适用范围.json`
- `生成产物/表格/账户修改功能适用范围.pptx`
- `生成产物/表格/预约查询.json`
- `生成产物/表格/预约查询.pptx`

##### 2.3.3 生成产物/演示/
**职责**：存放演示 PPT 文件

**内容**：
- `演示.pptx` - 演示文稿
- `演示_*.pptx` - 其他演示文件

##### 2.3.4 生成产物/输出/
**职责**：存放最终输出文档

**内容**：
- `最终输出.pptx` - 最终生成的 PPT
- `最终输出_*.pptx` - 其他最终输出

#### 2.4 输出文档/ (Output Documents)

**职责**：存放项目输出文档

**内容**：
- `最终输出.pptx` - 最终生成的 PPT
- `最终输出_*.pptx` - 其他最终输出

**注意**：此目录为最终产出目录，所有生成的 PPT 应该放在这里。

## 文件命名规范

### 通用规范

1. **小写字母 + 下划线**
   - ✅ `generate_page.py`
   - ❌ `GeneratePage.py`
   - ❌ `generate-page.py`

2. **中文命名**
   - ✅ `个人综合签约.docx`
   - ❌ `personal_contract.docx`（除非有特殊要求）

3. **清晰描述**
   - ✅ `账户修改功能适用范围.json`
   - ❌ `data.json`
   - ❌ `temp.json`

### 文件扩展名

- `.py` - Python 脚本
- `.md` - Markdown 文档
- `.json` - JSON 数据
- `.pptx` - PowerPoint 文件
- `.docx` - Word 文档
- `.txt` - 文本文件
- `.csv` - CSV 文件
- `.bat` / `.ps1` - 批处理脚本

## 技能产物管理

### 过程产物

**存放位置**：技能包目录内

**内容**：
- `SKILL.md` - 技能说明文档
- `templates/` - 模板文件
- `styles/` - 样式定义
- `recipes/` - 配方文件
- `examples/` - 示例文件

### 最终产物

**存放位置**：`生成产物/` 目录

**分类**：

1. **表格产物**：`生成产物/表格/`
2. **文档产物**：`生成产物/输出/`
3. **演示产物**：`生成产物/演示/`
4. **拆分文档**：`生成产物/拆分/`

## 检查清单

在提交代码前，请检查：

- [ ] 所有生成的 PPT 是否放在 `生成产物/输出/` 或 `生成产物/表格/`
- [ ] 所有脚本是否放在 `生成脚本/` 或 `tools/`
- [ ] 所有文档是否放在 `文档/` 或技能包内
- [ ] 文件命名是否符合规范
- [ ] 临时文件是否已清理（如 `__pycache__`、`.bak` 文件）
