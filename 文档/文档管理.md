# 文档管理

本文档说明如何管理 lark-training-ppt-generator 项目的文档。

## 快速开始

### 1. 整理文档

使用文档整理工具自动整理项目文档：

```bash
py -3 tools/organize_documents.py
```

这个脚本会：
- 检查并创建必要的目录
- 整理生成的文件到正确的位置
- 删除临时文件（`__pycache__`、`.bak` 文件）

### 2. 查看文档结构

整理完成后，项目目录结构如下：

```
lark-training-ppt-generator/
├── 输入文档/              # 原始输入文档
├── 生成脚本/              # 生成脚本
├── 生成产物/              # 生成产物
│   ├── 表格/              # 表格相关产物
│   ├── 演示/              # 演示文稿
│   └── 输出/              # 最终输出
├── 输出文档/              # 最终输出文档
├── 技能包/                # 技能包目录
├── 工具/                  # 辅助工具
└── 文档/                  # 项目文档
    ├── 项目说明/          # 项目说明
    ├── 使用指南/          # 使用指南
    ├── 设计文档/          # 设计文档
    ├── 开发文档/          # 开发文档
    └── 变更记录/          # 变更记录
```

## 目录职责

### 输入文档/
存放原始输入文件（.docx）

### 生成脚本/
存放所有生成脚本（.py、.js、.ps1）

### 生成产物/
存放所有生成的中间产物和最终产物

#### 生成产物/表格/
表格相关的生成产物（.json、*.pptx）

#### 生成产物/演示/
演示 PPT 文件（*.pptx）

#### 生成产物/输出/
最终输出文档（*.pptx）

### 输出文档/
存放项目输出文档（最终生成的 PPT）

### 技能包/
存放各个技能包

每个技能包包含：
- `SKILL.md` - 技能说明文档
- `templates/` - 模板文件
- `styles/` - 样式定义
- `recipes/` - 配方文件（如果有）

### 工具/
存放辅助工具（.py）

### 文档/
存放项目文档

#### 文档/项目说明/
- `README.md` - 项目说明
- `CHANGELOG.md` - 变更日志
- `CONTRIBUTING.md` - 贡献指南

#### 文档/使用指南/
- `快速开始.md` - 快速开始指南
- `使用手册.md` - 详细使用手册
- `API文档.md` - API 文档

#### 文档/设计文档/
- `设计规范.md` - 设计规范
- `架构设计.md` - 架构设计
- `技术选型.md` - 技术选型

#### 文档/开发文档/
- `开发指南.md` - 开发指南
- `测试文档.md` - 测试文档
- `部署文档.md` - 部署文档

#### 文档/变更记录/
- `变更日志.md` - 变更日志
- `问题记录.md` - 问题记录

## 文件命名规范

### Python 脚本

**规范**：小写字母 + 下划线

**示例**：
- ✅ `generate_page.py`
- ✅ `gen_table.py`
- ✅ `extract_table_data.py`
- ❌ `GeneratePage.py`
- ❌ `generate-page.py`

### JSON 数据

**规范**：清晰描述数据内容

**示例**：
- ✅ `账户修改功能适用范围.json`
- ✅ `预约查询.json`
- ✅ `slide_plan.json`
- ❌ `data.json`
- ❌ `temp.json`

### PPT 文件

**规范**：清晰描述内容

**示例**：
- ✅ `账户修改功能适用范围.pptx`
- ✅ `预约查询.pptx`
- ✅ `演示.pptx`
- ❌ `table.pptx`
- ❌ `demo.pptx`

### Markdown 文档

**规范**：清晰描述文档内容

**示例**：
- ✅ `使用手册.md`
- ✅ `API文档.md`
- ✅ `设计规范.md`
- ❌ `doc.md`
- ❌ `readme.md`

## 技能产物管理

### 过程产物

**存放位置**：技能包目录内

**内容**：
- `SKILL.md` - 技能说明文档
- `templates/` - 模板文件
- `styles/` - 样式定义
- `recipes/` - 配方文件
- `examples/` - 示例文件

### 最终产物

**存放位置**：`生成产物/` 目录

**分类**：
- 表格产物：`生成产物/表格/`
- 文档产物：`生成产物/输出/`
- 演示产物：`生成产物/演示/`
- 拆分文档：`生成产物/拆分/`

## 检查清单

在提交代码前，请检查：

- [ ] 所有生成的 PPT 是否放在 `生成产物/输出/` 或 `生成产物/表格/`
- [ ] 所有脚本是否放在 `生成脚本/` 或 `tools/`
- [ ] 所有文档是否放在 `文档/` 或技能包内
- [ ] 文件命名是否符合规范
- [ ] 临时文件是否已清理（如 `__pycache__`、`.bak` 文件）

## 常见问题

### Q: 为什么要把生成的 PPT 放在 `生成产物/` 而不是根目录？

A: 根目录应该保持简洁，生成的产物应该有专门的存放位置，便于管理和查找。

### Q: 临时文件（如 `__pycache__`）应该怎么处理？

A: 临时文件应该在每次提交前清理，可以使用 `tools/organize_documents.py` 脚本自动清理。

### Q: 技能包的产物应该放在哪里？

A: 技能的过程产物（模板、样式、配方等）放在技能包目录内，生成的最终产物放在 `生成产物/` 目录。
